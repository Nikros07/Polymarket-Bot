Features

Everything you need to bet smarter

A production-grade system combining quantitative scoring with multi-perspective AI debate.

🤖

10-Agent OASIS Pipeline

Scanner → Parser → Researcher → Predictor → Analyst ↔ Skeptic → Debate → Scenario → Validator → Synthesizer → Scorer. Every prediction debated from multiple angles.

📊

Kelly Criterion Sizing

Quarter-Kelly position sizing (25%) with hard block on negative Kelly. Fee-adjusted edge calculation deducting Polymarket's 2% fee before every decision.

⚡

Real-Time SSE Streaming

Server-Sent Events stream each agent's progress live. Watch the debate unfold as it happens — no polling, no waiting.

🆓

Free to Run

No Polymarket API key needed (public Gamma API). Works with free OpenRouter models like Llama 3.3 70B. Only Tavily for research (1000 free req/month).

🧠

Memory & Learning

SQLite persistence stores all decisions cross-session. Pattern detection identifies recurring event types and agent disagreements over time.

⚽

🔌

Multi-Provider LLM

camel-ai/OASIS native with fallback chain: Anthropic → OpenAI → OpenRouter. Switch models with a single env var, no code changes.

Wisdom-of-Crowd Personas

Architecture

The 10-Agent Pipeline

Sequential stages with parallel execution where possible. Each agent can fail independently — the pipeline always completes.

Stage 1 — Scan & Parse
01 ScannerAgent Extracts entities, event type, teams, sport, timeframe
02 InputParserAgent Canonical query normalization, parsing issues
↓
Stage 2 — Research
03 ResearchAgent Web research synthesis (Tavily/Serper), data quality score
↓
Stage 3 — Prediction
04 PredictorAgent Initial probability estimate 0.0–1.0 with uncertainty range
↓
Stage 4 — Debate PARALLEL
05 AnalystAgent Builds strongest bull case, argument strength score
06 SkepticAgent Challenges prediction, finds flaws, bear case
07 DebateAgent Structured debate: declares winner, key disagreements, post-debate probability range
↓
Stage 5 — Scenarios
08 ScenarioAgent Models 4–6 alternative outcomes, tail risk, variance
↓
Stage 6 — Validation
09 ValidatorAgent Checks logic consistency, detects cognitive biases
↓
Stage 7 — Synthesis & Score
10 SynthesizerAgent Integrates all perspectives, preserves conflicts, final narrative
★ ScoringAgent + DecisionEngine Weighted scoring formula → BET / WATCH / SKIP with Kelly fraction
Scoring Logic

How decisions are made

A weighted formula across 7 components. Decisions gated by edge, confidence, risk, and Kelly Criterion.

// Kelly Criterion (quarter-Kelly)
kelly = (b·p − q) / b × 0.25
// Fee-adjusted edge
edge = (p − implied_p) − 0.02
adj_edge = edge × confidence

Decision Gates

BET
  • ✓ adj_edge ≥ 10%
  • ✓ confidence ≥ 65%
  • ✓ risk < 70%
  • ✓ kelly > 0
WATCH
  • ✓ net_edge ≥ 3%
  • OR composite > 58%
SKIP
  • ✗ Insufficient edge
  • ✗ High risk (≥ 70%)
  • ✗ Negative Kelly
  • ✗ EXTREME risk level

Setup

Get running in minutes

Works with free models. Only an OpenRouter API key is required.

1

Clone & install

git clone https://github.com/nikros07/polymarket-bot
cd polymarket-bot
pip install -r requirements.txt
2

Configure environment

cp .env.example .env
# Edit .env:
LLM_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-v1-your-key
LLM_MODEL=meta-llama/llama-3.3-70b-instruct:free
3

Start the backend

python -m backend.main
# API running at http://localhost:8000
# Swagger docs at http://localhost:8000/docs
4

Launch Streamlit UI

streamlit run streamlit_app.py
# Opens http://localhost:8501
